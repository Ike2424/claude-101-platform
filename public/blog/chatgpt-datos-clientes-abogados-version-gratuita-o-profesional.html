¿Puedo usar ChatGPT con datos de clientes? Versión gratuita, de pago y profesional

Es la pregunta más repetida en los despachos. La respuesta corta: depende de qué versión uses y de qué datos pegues. Aquí va la respuesta larga, con una tabla de decisión.

Divulgación; no es asesoramiento jurídico. Revisa las condiciones vigentes de cada proveedor.

La respuesta corta

No conviene introducir datos identificables de clientes en una versión gratuita o de consumo de una IA. La Circular 3/2026 del CGAE, según el análisis de Confilegal, advierte precisamente de que las condiciones de estas versiones pueden permitir usar lo que escribes para entrenar modelos, algo difícilmente compatible con la protección de datos. Sí puedes usarlas con datos anonimizados.

Cómo anonimizar bien

  • Sustituye nombres y razones sociales por marcadores.
  • Elimina DNI/NIE, direcciones, teléfonos, IBAN y números de expediente.
  • Generaliza fechas o cifras si permiten identificar el caso.
  • Revisa los metadatos de los archivos que subas.

Y además

  • Desactiva el uso de tus conversaciones para entrenar modelos, si la herramienta lo permite.
  • No compartas conversaciones por enlace público.
  • Valora informar al cliente cuando el uso de IA le afecte.

Preguntas frecuentes

¿Puedo pegar datos de un cliente en ChatGPT gratuito?

No es recomendable. Las versiones de consumo pueden usar tus entradas para entrenar modelos; usa texto anonimizado.

¿Es seguro el plan profesional de una IA?

Suele ofrecer más garantías contractuales, pero debes revisar sus condiciones, el tratamiento de datos y documentar la decisión antes de usar datos reales.

¿Qué es anonimizar un documento?

Eliminar o sustituir todo dato que permita identificar a una persona, incluidos nombres, identificadores, direcciones y otros datos indirectos.
