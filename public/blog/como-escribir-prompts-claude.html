Cómo escribir prompts para Claude

El 80% de los malos resultados con una IA no son culpa de la IA: son culpa del prompt. Aquí tienes el método para escribir instrucciones que funcionan a la primera, con ejemplos que puedes copiar.

¿Qué es un prompt?

Un prompt es la instrucción que le das a la IA. Escribir buenos prompts (lo que se llama prompt engineering) consiste en dar contexto y pedir con claridad para que el modelo responda con precisión y en el formato que quieres.

Las 4 partes de un buen prompt

  1. Rol o contexto: "Eres un abogado revisando un contrato…".
  2. Tarea concreta: qué quieres exactamente, sin ambigüedad.
  3. Datos o material: el texto, la tabla o el ejemplo sobre el que trabajar.
  4. Formato de salida: "en 3 viñetas", "tabla", "máximo 100 palabras".

El truco que casi nadie usa: etiquetas XML

Claude responde especialmente bien cuando separas las partes del prompt con etiquetas tipo XML. Así distingue tus instrucciones de los datos sin confundirse:

<instrucciones> Clasifica el email en "venta", "soporte" o "queja" y extrae el nombre del cliente. </instrucciones> <email> [pega aquí el email] </email>

3 ejemplos copiables

Redacción

Reescribir con tono

"Reescribe este texto con tono cercano y profesional, como un asesor que habla con un cliente valioso. Máximo 5 frases. Texto: [...]"

Análisis

Resumir con criterio

"Resume este documento en decisiones, próximos pasos (con responsable) y temas pendientes. Máximo 200 palabras. Documento: [...]"

Ideas

Generar sin filtrar

"Dame 20 ángulos para una campaña sobre [tema]. No filtres: quiero extremos, técnicos y emocionales. Una línea cada uno."

Errores que arruinan un prompt

  • Contexto irrelevante: Claude pondera todo lo que le das. Incluye solo lo necesario.
  • Instrucciones en negativo: "no seas formal" funciona peor que "usa un tono conversacional".
  • Pedir demasiado a la vez: divide tareas grandes en pasos.

El prompting es iterativo: prueba, observa y refina. Para dominarlo, en el curso dedicamos un módulo entero a técnicas avanzadas. Antes, repasa cómo usar Claude.

Preguntas frecuentes

¿Qué es un buen prompt para Claude?

Uno que incluye rol o contexto, una tarea concreta, los datos necesarios y el formato de salida deseado. Cuanto más claro y específico, mejor responde.

¿Para qué sirven las etiquetas XML en Claude?

Sirven para separar las instrucciones de los datos (por ejemplo, etiquetas como instrucciones, email o documento), lo que ayuda a Claude a entender exactamente qué hacer sin mezclar partes.

¿Es mejor decirle a la IA qué hacer o qué no hacer?

Es más efectivo decirle qué hacer. Las instrucciones en positivo ("usa un tono conversacional") funcionan mejor que las negativas ("no seas formal").
