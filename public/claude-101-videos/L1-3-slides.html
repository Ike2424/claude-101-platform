Atención: el mecanismo

Click para revelar

Claude usa "atención" para pesar qué tokens anteriores son relevantes. Tokens importantes = peso alto. Irrelevantes = peso bajo.

Click para ocultar

La atención es lo que permite "focus" en lo importante.

Lección 1-3

Por qué Chain of Thought funciona

  • Claude razona escribiendo sus pensamientos token a token
  • Escribir pasos intermedios = mejores predicciones posteriores
  • Es como pensar en voz alta — ordena sus ideas al escribir
  • CoT mejora especialmente en razonamiento matemático

Esta es la razón de todo el éxito de CoT.

Lección 1-3

Ejemplo: CoT real

Sin CoT:
"¿Cuánto es 17×3?"
→ "51" (a veces falla)

Con CoT:
"¿Cuánto es 17×3? Razona paso a paso"
→ "17×3 = 17+17+17 = 51" (siempre funciona)

La diferencia es drástica en problemas complejos.

Lección 1-3

Temperatura y aleatoriedad

Click para revelar

Temperatura alta = más aleatoriedad (creativo). Baja = determinista (consistente). Default: ~1.0. Para datos: 0. Para creatividad: 1+.

Click para ocultar

Ajustar temperatura cambia drásticamente el comportamiento.

Lección 1-3

Temperatura baja vs alta

T=0 (Determinista)

  • Siempre misma respuesta
  • Para datos
  • Para reproducibilidad

T=1+ (Creativo)

  • Respuestas variadas
  • Para brainstorm
  • Para escritura

Elige según tu caso de uso.

Lección 1-3

Contexto efectivo

Click para revelar

Claude procesa contexto en orden. Tokens al inicio = menos peso que al final (recency bias). Repite lo importante o colócalo al final.

Click para ocultar

Esto es crucial para optimizar grandes contextos.

Lección 1-3

Cómo aprovechar el reasoning

Pide CoT para problemas complejos ("razona paso a paso")
Verifica hechos críticos (Claude puede alucinar)
Usa contexto corto y enfocado
Repite lo crítico — no confíes en atención

Estas prácticas mejoran radicalmente los resultados.
