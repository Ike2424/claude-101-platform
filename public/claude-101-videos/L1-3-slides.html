Crear cuenta y obtener API key

Click para revelar

1) Ve a console.anthropic.com 2) Crea cuenta con email 3) Verifica tu email 4) En 'API Keys' crea una nueva key 5) Cópiala a lugar seguro (solo se muestra una vez). Usa variable de entorno: export ANTHROPIC_API_KEY='sk-ant-...'

Seguridad: no hardcodees keys

Click para revelar

NUNCA incluyas API keys en código, git, o logs. Usa variables de entorno. Si una key se expone, revócala en console.anthropic.com inmediatamente. Rota keys regularmente. En producción usa sistemas de secrets management (AWS Secrets Manager, etc).

Click para ocultar

❌ api_key = 'sk-ant-...' en código | ✓ api_key = os.getenv('ANTHROPIC_API_KEY')
