Constitutional AI

Claude no se entrena solo con feedback humano. Se autoevalúa contra una constitución escrita.

La constitución
Principios
Sé útil, honesto e inofensivo.
Da contexto cuando no estés seguro.
Razona en lugar de bloquear.
Respeta la autonomía del usuario.
→se aplica a
Bucle de auto-revisión
1. Claude responde
2. Se evalúa a sí mismo
3. Revisa según la constitución
4. Refina la respuesta

Markdown semántico

Claude está entrenado con millones de documentos en markdown. Estructura tu prompt como él piensa.

✗ Muro de texto
Hazme un resumen de la reunión incluyendo decisiones acuerdos próximos pasos y responsables y también extrae datos clave y luego clasifícalos por prioridad y devuélvelo en un formato claro
✓ Markdown estructurado
## Tarea Resume la reunión. ## Secciones - Decisiones - Acuerdos - Próximos pasos - Responsables ## Formato Markdown con headers ##
↑ Mismo input. Pero Claude lo procesa como jerarquía, no como párrafo.

Skills

Capacidades empaquetadas que Claude carga bajo demanda. Defines una vez, las reutilizas siempre.

📁 mi-skill/ ├── SKILL.md // frontmatter + descripción ├── 📁 templates/ // plantillas reutilizables ├── 📁 scripts/ // código auxiliar └── 📁 ejemplos/ // few-shot examples
// SKILL.md --- name: resumir-reunion description: Convierte transcripciones en resúmenes ejecutivos --- # Cuándo usar # Cuando el usuario sube una transcripción .vtt o .txt larga.
