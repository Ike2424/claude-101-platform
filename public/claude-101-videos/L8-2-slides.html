Model Context Protocol (MCP)

Protocolo para integrar herramientas

Qué es MCP ▼

Estándar abierto para conectar Claude con herramientas externas. APIs, DBs, servicios.

Cómo funciona ▼

Claude envia mensajes a MCP. MCP ejecuta acciones. Devuelve resultados. Loop bidireccional.

Casos de uso ▼

Acceso a datos en tiempo real. Ejecución de scripts. Integración con sistemas legacy. APIs personalizadas.

Crear MCP ▼

Especificación abierta. Lenguaje agnóstico. Documentación disponible. Comunidad creciente.
