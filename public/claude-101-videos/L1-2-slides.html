Cómo calcular costos

Click para revelar

Precio = (input_tokens × input_price + output_tokens × output_price) / 1,000,000. Ej: 10,000 input tokens + 5,000 output tokens con Sonnet = ($3×10 + $15×5) / 1M = $105 / 1M = $0.000105
