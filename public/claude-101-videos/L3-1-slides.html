Formatos soportados

Click para revelar

Claude soporta: JPEG, PNG, WebP, GIF. Límite: 5MB por imagen. Puedes pasar en 3 formatos: base64 (imagen codificada como string), URL (link a imagen en internet), o File upload (desde tu disco).

Click para ocultar

base64: 'data:image/png;base64,iVBORw0KGgo...' o URL: 'https://example.com/image.jpg'

Usar base64

Click para revelar

Convierte imagen a base64: python -c 'import base64; print(base64.b64encode(open("img.jpg","rb").read()).decode())' Luego en prompt: {'type': 'image', 'source': {'type': 'base64', 'media_type': 'image/jpeg', 'data': ''}}

Usar URLs

Click para revelar

Si tu imagen está en internet, simplemente pasa el URL: {'type': 'image', 'source': {'type': 'url', 'url': 'https://example.com/image.jpg'}} Claude descargará y analizará. Más simple que base64.

Click para ocultar

Restricciones y límites

Click para revelar

Máximo 5 imágenes por request. Máximo 5MB por imagen (total ~25MB). Resolución: mayor resolución = mejor análisis pero más tokens. Claude puede no reconocer imágenes muy pequeñas o borrosas.

Click para ocultar

Imagen 1920x1080 = ~500 tokens. Imagen 200x200 = ~50 tokens
