# Casas del Albayzín — web de pisos turísticos

Sitio estático (HTML + CSS + JS, sin dependencias) con 5 páginas:
`index.html`, `apartamentos.html`, `resenas.html`, `faq.html`, `contacto.html`.

## Verlo en local

```bash
cd albayzin-site
python3 -m http.server 8080
```

Abre http://localhost:8080

Pendiente antes de publicar: nº de registro VFT real, teléfono/email reales,
fotos reales, textos legales y conectar el formulario a un servicio de envío.
