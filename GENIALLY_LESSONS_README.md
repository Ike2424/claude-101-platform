## JavaScript Interactivo

### Tab Switching
```javascript
- Click en tab → activate
- Transición smooth 0.4s
- Solo un tab activo a la vez
```

### Accordion Toggle
```javascript
- Click en header → expand/collapse
- Max-height animation
- Solo un item abierto (opcional, configurable)
```

### Quiz Feedback
```javascript
- Click en opción → mostrar resultado
- Green si correcto
- Red si incorrecto
- No permite cambiar respuesta
```

### Scroll Reveal (IntersectionObserver)
```javascript
- Detecta cuando sección entra en viewport
- Aplica animation-delay staggered
- Smooth fade-in
```

## Personalización

### Cambiar Color de Módulo
En `<style>`, modificar:
```css
:root {
    --color-primary: #NEW_COLOR; /* Color módulo */
    --color-secondary: #GRADIENT_COLOR;
}
```

### Agregar Más Contenido
Estructura base está lista para scalabilidad:
- Más tabs: Solo agregar `<button>` y `.tab-content`
- Más acordeones: Copiar `.accordion-item`
- Más pasos: Copiar `.step`

### Responsiveness
Ya optimizado con media queries en 3 breakpoints:
- 768px (tablets)
- 480px (mobile)
- Fluido en todo rango
